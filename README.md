# TeleGuardian

*一個簡單的 Telegram 群組管理機器人，保護你的群組不受大量垃圾訊息打擾。*

## 核心功能

- **自動違規處置機制**：
    - **第 1 次違規**：發送警告訊息。
    - **第 2 次違規**：自動禁言 10 分鐘。
    - **第 3 次違規**：永久封鎖用戶並清除違規紀錄。
- **互動式管理**：
    - 機器人發出的違規通知附帶**管理按鈕**，管理員可即時選擇「忽略」（恢復權限、次數扣減）或「永久封鎖」。
- **多元過濾規則**：
    - **連結阻擋**：自動刪除包含 URL 或文字連結的訊息（管理員與白名單除外）。
    - **違禁詞過濾**：支援動態添加違禁詞，包含關鍵字的訊息將被即時刪除。
    - **標記限制**：防止用戶標記非白名單內的用戶。
    - **轉發限制**：嚴格檢查訊息轉發來源，僅允許來自白名單頻道的轉發內容。
- **白名單管理**：
    - **用戶白名單**：豁免於連結與標記限制。
    - **頻道白名單**：允許來自特定頻道的轉發內容與外部回覆。
    - **智慧清理**：機器人發出的通知訊息將在 180 秒後自動刪除，保持群組整潔。

## 安裝

1. 確保已安裝 Python 3.8+
2. 下載專案並安裝必要依賴：

```bash
pip install -r requirements.txt
```

## 環境變數

請在根目錄建立 `.env` 檔案：

```bash
TELEGRAM_BOT_TOKEN='你的機器人_Token'
FIRST_ADMIN_ID='主管理員_Telegram_ID'
```

## 管理指令

*僅限機器人管理員使用：*

- **管理員設置**：`/addadmin` (回覆訊息或帶 ID), `/deladmin`
- **用戶白名單**：`/addwl`, `/delwl`
- **頻道白名單**：`/addcwl [頻道ID]`, `/delcwl [頻道ID]`
- **違禁詞管理**：`/addword [詞彙]`, `/delword [詞彙]`

## 啟動

```bash
python main.py
```

## 常見問題 (Troubleshooting)

- **權限不足**：確保機器人已被提升為群組管理員，且擁有「刪除訊息」與「封鎖用戶」的權限。
- **資料庫**：系統會自動生成 `manage.db` SQLite 資料庫文件，請勿隨意移動或刪除。
